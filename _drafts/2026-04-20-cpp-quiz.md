1. What is the value of `x` after the following code is executed?
```cpp
int x = 0; 
x = x++;
```
Answer:
0.

First, `x++` will evaluate to 0, as the original value is returned. 
Then, it will execute the `x = 1` side effect from the right side _before_
executing `x = 0`, so `x` ends up as 0.
